What's New in v0.4.0

  • Signed release build First APK signed with the official Black Pulse keystore — no more debug builds
  • New app icon Sheet-music style BP monogram on paper texture, with a matching notification icon
  • Last played song memory The mini-player remembers your last track — reopen and it's there, paused
  • Notification fixes Persistent Queue removed — notifications now clear properly when you close the app
  • All Settings sections inline 10 sections accessible via the Settings rail, no more navigating away
  • Search filter rail All, Songs, Playlists, Artists, Albums, Videos, Podcasts — ViMusic-style layout

About

Black Pulse is a fork of Metrolist, which is built on InnerTune. Design inspired by ViMusic. Licensed under GPL v3.0.
