What's New in v0.4.0

  • Signed release build First APK signed with the official Black Pulse keystore — no more debug builds. Smaller file size (~28 MB vs ~51 MB before).
  • New app icon Sheet-music style BP monogram on paper texture, with a matching notification icon.
  • Last played song memory The mini-player remembers your last track — reopen the app and it's there, paused, ready to resume.
  • Notification fixes Persistent Queue removed — notifications now clear properly when you close the app.
  • Settings rail with 10 sections About, Appearance, Player, Content, AI, Android Auto, Privacy, Storage, Backup, Updater — all inline, no more navigating away.
  • Search filter rail All, Songs, Playlists, Artists, Albums, Videos, Podcasts — ViMusic-style vertical layout.
  • Vertical rail navigation ViMusic-inspired layout with rotated text, transparent background, and dynamic Material You colors that adapt to your wallpaper.
  • Full rebranding File headers, user-visible strings, About screen — all updated to Black Pulse.

About

Black Pulse is a fork of Metrolist, which is built on InnerTune. Design inspired by ViMusic. Licensed under GPL v3.0.

Install

Download the APK and open it on your Android phone. If you're upgrading from v0.3.0 or earlier, uninstall the old version first — the signing key changed.
